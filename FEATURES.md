# Ono — Feature Catalog

> Personal transformation app for young men (18–30). Four lanes of growth: Mind 🧠, Body 💪, Social 🗣, Skill 📚.

---

## Core Systems

### 1. AI-Powered Blueprint Generation
**Status:** ✅ Live  
**Files:** `screens/blueprint_loading_screen.dart`, `screens/blueprint_screen.dart`, `providers/blueprint_provider.dart`, `gateways/blueprint_gateway.dart`  
**Backend:** `generate-blueprint` Edge Function  

Personalized 90-day transformation plan generated by AI based on the user's archetype and assessment answers. The blueprint defines daily actions across all four lanes, with milestones and lane-specific goals.

### 2. Archetype System
**Status:** ✅ Live  
**Files:** `screens/archetype_screen.dart`  
**Backend:** `archetypes` table (5 seeded: Executive, Athlete, Creative, Builder, Gentleman)  

Users select an identity archetype that shapes their entire experience — from the actions they receive to the language in their blueprint.

### 3. Assessment Flow
**Status:** ✅ Live  
**Files:** `screens/assessment_screen.dart`  
**Backend:** `assessments` table  

Multi-step questionnaire that evaluates the user's current state across all four lanes. Results feed directly into blueprint generation for maximum personalization.

### 4. Daily Actions Engine
**Status:** ✅ Live  
**Files:** `screens/home_screen.dart`, `providers/daily_actions_provider.dart`, `gateways/actions_gateway.dart`  
**Backend:** `daily_actions` table, `seed-actions` Edge Function  

Each day, Ono serves a fresh set of actions drawn from the user's blueprint. Actions are lane-tagged (mind/body/social/skill), completable with a single tap, and auto-seeded each morning from the active blueprint.

### 5. Streak Tracking
**Status:** ✅ Live  
**Files:** `providers/daily_actions_provider.dart`  
**Backend:** `streaks` table  

Consecutive-day completion tracking. The streak counter is front and center on the home screen, reinforcing daily consistency.

### 6. Lane Score Progress
**Status:** ✅ Live  
**Files:** `providers/progress_provider.dart`, `screens/progress_screen.dart`  
**Backend:** `lane_scores` table  

Each lane (mind, body, social, skill) has an independent score (0–100%) calculated from action completion. The progress screen visualizes all four lanes with progress bars, strongest/weakest lane callouts, and an overall score.

### 7. Weekly Snapshots
**Status:** ✅ Live  
**Files:** `providers/progress_provider.dart`  
**Backend:** `weekly_snapshots` table, `weekly-snapshot` Edge Function  

Automated weekly rollup that captures lane scores, overall score, and action completion stats. Powers the week-over-week trend tracking.

## Engagement & Motivation

### 11. Daily Challenges
**Status:** ✅ Built (client-side)  
**Files:** `models/challenge.dart`, `widgets/challenge_card.dart`  

20 micro-challenges across all four lanes — quick 5-minute pushes that earn XP. One offered per day, deterministic by day-of-year. Three-state interaction: view → accept → complete.

**Examples:**
- 🧊 Cold Open — No phone for first 30 min after waking
- 💪 Drop & Give 20 — 20 push-ups right now
- 💬 Genuine Compliment — Give a specific compliment today
- ✍️ Write 200 Words — Write about anything

### 12. Weekly Challenges
**Status:** ✅ Built (client-side)  
**Files:** `models/challenge.dart`, `widgets/challenge_card.dart`  

8 stretch challenges — bigger week-long commitments worth more XP. Rotate weekly.

**Examples:**
- 🚫 Sugar-Free Week — Cut all added sugar for 7 days
- ⏰ 5AM Club — Wake at 5 AM every day this week
- 🏋️ Iron Week — Work out 5 times this week
- 🗣 Talk to 5 Strangers

### 13. Streak Celebrations
**Status:** ✅ Live  
**Files:** `widgets/streak_celebration.dart`  

Confetti animation dialog triggered at milestone days: 3, 7, 14, 21, 30, 60, 100, 365. Each milestone has a unique emoji, title, and motivational message. Custom confetti painter for particle effects.

### 14. Achievement Badges
**Status:** ✅ Live  
**Files:** `models/achievement.dart`, `widgets/achievements_section.dart`  

15 unlockable badges displayed on the profile screen in a grid. Locked badges show 🔒, unlocked show their emoji. Tap for detail dialog.

**Badge categories:**
- Action milestones: First Action, 10/50/100 Actions
- Streak milestones: 3/7/14/30/100-Day Streak
- Lane mastery: 50% Lane, 80% Lane, All Lanes 50%
- Membership: 7/30/90-Day Member

### 15. Reflection Journal
**Status:** ✅ Built (UI only — persistence TODO)  
**Files:** `widgets/reflection_sheet.dart`  

After completing any action, a bottom sheet slides up with a random reflection prompt ("How did that feel?", "What did you learn?", etc.). Users write a quick 280-character thought. Skip or save.

**Next:** Persist reflections to Supabase for journaling history.

### 16. Daily Wisdom Quotes
**Status:** ✅ Live  
**Files:** `screens/home_screen.dart`  

30 curated motivational quotes that cycle daily on the home screen. Designed to resonate with young men on a self-improvement journey.

### 17. Weekly Review Screen
**Status:** ✅ Built  
**Files:** `screens/weekly_review_screen.dart`  
**Route:** `/weekly-review` (accessible from Progress tab)  

Full-screen breakdown of the week: overall score, week-over-week delta, streak count, actions completed/total, per-lane progress bars with strongest/weakest tags, and a "Next Week's Focus" recommendation targeting the weakest lane.
